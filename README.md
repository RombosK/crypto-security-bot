# Криптобезопасный помощник — Telegram-бот

Учебный проект по информатике для 10 класса.

## Описание

Telegram-бот с двумя модулями:
1. **Генератор паролей** — создаёт криптостойкие пароли и оценивает их стойкость (энтропия, время взлома)
2. **Антимошеннический анализатор** — проверяет текст сообщения на признаки мошенничества по взвешенной системе признаков (скор 0–100) и базе известных схем

## Стек

- Python 3.10+
- aiogram 3.x (Telegram Bot API)
- Без внешних API и ML — чистый Python, стандартная библиотека

## Установка и запуск

### 1. Получите токен бота

1. Откройте Telegram, найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Задайте имя и username бота
4. Скопируйте полученный токен

### 2. Установите зависимости

```bash
cd crypto-security-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройте токен

```bash
cp .env.example .env
# Откройте .env и вставьте токен:
# TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
```

### 4. Запустите бота

```bash
python src/main.py
```

Или:

```bash
python -m src.main
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и список команд |
| `/help` | Подробная справка |
| `/password` | Сгенерировать пароль (16 символов по умолчанию) |
| `/password 20` | Пароль длиной 20 символов |
| `/password 12 nosym` | 12 символов без спецсимволов |
| `/check` | Проверить сообщение на мошенничество |
| `/schemes` | Список известных мошеннических схем |
| `/stats` | Статистика проверок |

### Автоопределение

- **Короткий текст без пробелов** — бот проверяет его как пароль
- **Длинный текст** — бот анализирует на признаки мошенничества
- Можно просто перешлите подозрительное сообщение боту

## Модульная архитектура

Проект разделён на независимые модули, каждый из которых можно использовать отдельно:

- `password_engine.py` — импортируйте `generate_password()` или `assess_strength()` в любой Python-проект
- `fraud_detector.py` — импортируйте `analyze_message()` для анализа текста
- `main.py` — связывает модули с Telegram Bot API

Это позволяет расширять проект: добавить веб-интерфейс, REST API или другие мессенджеры, не переписывая логику.
